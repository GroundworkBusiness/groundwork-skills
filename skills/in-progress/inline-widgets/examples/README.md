# Examples

One complete widget per module, named after the module it demonstrates. Pass a file's contents to
the show_widget tool as it stands and it renders. The CSS variables and ramp classes come from the
host, so open these through the tool and not a browser.

**Follow a module's structure and vary the composition. Never clone an example wholesale.** The
next widget has its own subject, its own data and its own layout within the same rules. One
composition reused across a set reads as a template.

Every HTML example carries the same four kinds of interaction: an action row with at least one ↗
button, drill-in on rows or marks, detail on hover, and at least one local control. The SVG
example has click-throughs and hover detail, and no local control.
