# ChatGPT Work

Download the selected skill's ZIP from the [library](../../README.md#choose-a-skill). Keep the ZIP intact for upload.

## If your workspace offers skill uploads

1. Open a **Work** task.
2. Open the skills area. Some interfaces place it under **Plugins > Skills**; others expose **Skills** directly.
3. Use the add or create control and choose the option to upload from your computer.
4. Upload the ZIP, then select the installed skill in your task. ChatGPT supports `@` mentions for selecting skills.

In ChatGPT on the web, use these upload steps. Asking the chat to install an attached ZIP checks the package but does not finish installing it.

In the ChatGPT desktop app you can skip them: switch the chat to **Work**, attach the ZIP and ask ChatGPT to add the skill. It installs the skill with all of its files, on that computer only, so upload it as well if you also use ChatGPT on the web. Either way, confirm the skill appears in your skill list.

## If there is no skill upload option

Availability differs between surfaces and workspaces. OpenAI currently documents standalone skills for the desktop app, Codex CLI, and IDE extension, and plugin-bundled skills across Chat and Work on web, desktop, and mobile. These downloads are standalone skill packages.

Use the desktop skill interface where available, follow the [Codex guide](codex.md), or try the [single-file prompt route](README.md#try-a-single-file-skill-as-a-prompt) for a skill that needs no supporting files. An organization administrator may need to enable the relevant feature.

Sources: [Build skills](https://learn.chatgpt.com/docs/build-skills) and [Skills & Plugins](https://learn.chatgpt.com/docs/skills-and-plugins). Documentation checked: September 21, 2026. Attached-ZIP install tested on the web and in the desktop app: October 21, 2026. Menu steps are conditional on the upload controls present in your workspace.
